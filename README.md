# Awaaz-e-Azaadi

Independence Day nostalgia radio site built with Next.js App Router + TypeScript + Tailwind CSS v4.

## Run

1. Install Node 20+.
2. In this folder run:
   `npm install`
3. Then:
   `npm run dev`
4. Open the local URL shown by Next.js.

## Important music note

The starter UI deliberately does not ship copyrighted song/video IDs. Add only tracks you own, have permission to use, or that are served by the rights holder with embedding enabled. The current playlist is UI/demo metadata only.

## Artwork

`public/bg/scene-wide.png` is the generated wide Independence Day background. Add a separately composed `public/bg/scene-tall.png` later for a dedicated portrait layout.
