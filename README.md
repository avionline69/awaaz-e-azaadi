# Awaaz-e-Azaadi

Independence Day nostalgia radio experience built with Next.js App Router + TypeScript + Tailwind CSS v4.

## Run
1. Install Node 20+.
2. In this folder run `npm install`.
3. Then run `npm run dev`.
4. Open the local URL shown by Next.js.

## Visual alignment
The supplied `public/bg/scene-wide.png` is a complete composed artwork that already contains the title, radio console, playlist, clock, social controls, and footer artwork. The UI therefore uses an image-first layout and places only transparent functional interaction hotspots over the artwork. This prevents duplicate panels and text from drifting over the painted composition on desktop screens.
